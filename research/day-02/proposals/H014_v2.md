# Hypothesis H014 v2: matched M1 reference for H013 v2 (LightGBM on FS0, no random component)

Part of the Day 2 batch X-D02-S01-0005 (see `H013_v2.md`). **H014 is an ablation and never a promotion candidate.**

**v2 replaces v1** (`H014_v1.md`, ACCEPT in X-D02-S01-0004). v1's ACCEPT **lapsed by its own rule** (`H014_ack_v1.md`): H013 v2 adds `bin_construct_sample_cnt`, so v1's configuration no longer matches H013 v2. The only change from v1 is that parameter, which makes the training procedure have no random component on any fold, as H013 v2's does.

## Research Question

What does H013 gain from the six FS1 keys (M1) when the training configuration (no subsampling, bins from all rows: no random component) is held fixed?

## Observation

- H009's M1 reference was E006: FS0 with the same, bagged parameters.
- H013 changes the training configuration, so E006 is no longer a one-change reference. The M1 effect is small (E012 − E006 on `NM_present_excl_LIRF`: −7.16 s). The training-configuration change alone could be of similar size.

## Mechanism

None claimed. This is E006's model trained with no random component (no subsampling, bins from all rows), so that H013 v2 − H014 v2 isolates the six FS1 keys.

## Proposed Change

LightGBM on **FS0** (`fs0`, body unchanged since `866b902`), with E006's parameters except four, which are H013 v2's:
- `bagging_fraction` 1.0;
- `bagging_freq` 0;
- `feature_fraction` 1.0;
- `bin_construct_sample_cnt` 5,000,000 (≥ every fold's training rows; largest 1,919,370).

Seed 42. No other training parameter is set.

**Matched binning.** Because H013 v2 and H014 v2 both bin from **every** training row, their shared FS0 features get identical bins by construction, not only because they share a seed (the v1 condition).

## Controlled Variables

Identical to H013 v2 except the feature set (FS0 against FS1). Identical to E006 except the four parameters above.
