# Hypothesis H014: matched M1 reference for H013 (LightGBM on FS0, no subsampling)

Part of the Day 2 batch X-D02-S01-0004 (see `H013_v1.md`). **H014 is an ablation and never a promotion candidate.**

## Research Question

What does H013 gain from the six FS1 keys (M1) when the training configuration, with no subsampling, is held fixed?

## Observation

- H009's M1 reference was E006: FS0 with the same, bagged parameters.
- H013 changes the training configuration, so E006 is no longer a one-change reference. The M1 effect is small (E012 − E006 on `NM_present_excl_LIRF`: −7.16 s). The bagging change alone could be of similar size.

## Mechanism

None claimed. This is E006's model trained without subsampling, so that H013 − H014 isolates the six FS1 keys.

## Proposed Change

LightGBM on **FS0** (`fs0`, body unchanged since `866b902`), with E006's parameters except `bagging_fraction` 1.0, `bagging_freq` 0 and `feature_fraction` 1.0, which are H013's. Seed 42.

## Controlled Variables

Identical to H013 except the feature set (FS0 against FS1). Identical to E006 except the three subsampling parameters.
