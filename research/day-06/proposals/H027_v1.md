# Hypothesis H027 v1: a subsampled LightGBM twin of E029 (row and feature bagging, new seed); component of ladder rung A (control, not a candidate)

Batch X-D06-S01-0001. The claim under attack, the ladder, the readings and their thresholds, the noise reference, the batch status (no candidate, no holdout access), the shared validation plan, the tools freeze, the run window and order, the leakage analysis and the literature are in **H024 §Batch** (`research/day-06/proposals/H024_v1.md`) and apply here unchanged.

## Research Question

What does a same-family, similar-accuracy, partly decorrelated second model look like next to E029? H027 builds it; H028 blends it.

## Observation

E029 is deterministic (`feature_fraction` 1.0, `bagging_fraction` 1.0, `bagging_freq` 0, `deterministic=True`): a seed change alone reproduces it, so it cannot serve as its own averaging partner. Row and feature subsampling is the standard way to get decorrelated copies of one learner (Breiman 1996).

## Mechanism

Bagging and feature subsampling perturb split choices, which decorrelates errors on rows where several splits are near-tied, while accuracy stays close to the full model. It is the averaging-only control: same features, same learner, same tree shape, same routing.

## Proposed Change

`routed_lightgbm`, FS2, E029's configuration with **three changes**: `feature_fraction: 0.8`, `bagging_fraction: 0.8`, `bagging_freq: 1`, and seed 44 (E029: 43; the seed now drives the subsampling). The values are LightGBM's conventional subsampling defaults in its documentation examples, fixed a priori; nothing is tuned.

```yaml
model: routed_lightgbm
feature_set: FS2
params: {objective: regression, learning_rate: 0.05, num_leaves: 255, min_data_in_leaf: 100,
  feature_fraction: 0.8, bagging_fraction: 0.8, bagging_freq: 1,
  bin_construct_sample_cnt: 5000000, num_threads: 4, num_boost_round: 1000,
  route_train_exclude: true, route_ridge_params: {alpha: 1.0, winsor: [0.005, 0.995]}}
folds: [R1, R2, R3, S1, W1, S1c, W1c, H]
seed: 44
job_class: CLASS-M
```

## Controlled Variables

Features (FS2), learner, tree shape (255 leaves, `min_data_in_leaf` 100), learning rate, rounds, binning, routing and its ridge, folds, silver, `uv.lock`, environment. LightGBM stays deterministic under a fixed seed with `deterministic=True`, so H027 is reproducible on the laptop (rule 13 does not arise).
