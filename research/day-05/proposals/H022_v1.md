# Hypothesis H022 v1: the H021 CatBoost without categorical statistics (matched capacity control)

Batch X-D05-S04-0001 (see `H021_v1.md`). **Role:** the matched reference for H021's clause 1 under ruling R. **It is not a promotion candidate.** Provenance as H021.

## Research Question

What does H021's CatBoost achieve when its categorical columns carry no categorical statistic, at the same capacity, inputs and rows? This is Missing Control 3's "contrast whose only difference is the categorical handling, at fixed capacity".

## Observation

See H021. In CatBoost, a column declared categorical is used only through CTR statistics (and one-hot encoding up to `one_hot_max_size` 2). A column given as numbers is split by thresholds. Giving the same columns as integer codes therefore removes every categorical statistic, and nothing else.

## Mechanism

The control's own mechanism: a symmetric tree splits integer codes by threshold, so each split groups alphabetically adjacent levels. Useful level sets can only be isolated by spending splits. H022 measures how much of H021's accuracy survives without the statistics.

## Proposed Change

**H021's configuration with one parameter changed:** `cat_mode: codes` (`src/prc/models/gbm.py`).
- The nine categorical columns (`ADEP_mvt`, `airport_runway`, `WK_TBL_CAT_flt`, `MARKET_SEGMENT_flt`, `FLIGHT_TYPE_flt`, `stand`, `actype`, `op_prefix`, `ades`) enter as the integer codes of the fold's training vocabulary (sorted levels). Validation-only and null levels are NaN.
- No `cat_features` are declared. The CTR parameters stay in the configuration and are inert without categorical features (a GPU synthetic smoke test of both arms ran through `routed_catboost`).
- Everything else is H021's: FS2_RAW, routing, `route_train_exclude: true`, depth 8, 1,000 iterations, learning rate 0.08, border count 254, `l2_leaf_reg` 3, Plain boosting, `gpu_ram_part` 0.4, seed 42.
- **Test:** `tests/test_models.py::test_catboost_codes_mode_uses_no_categorical_features`. The fit receives no categorical feature indices, and the default (`ctr`) path is byte-identical to before.
